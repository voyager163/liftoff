# Getting help with Liftoff

## Choose the right channel

| You need to | Use |
| --- | --- |
| Ask a question or get help | [GitHub Issues](https://github.com/voyager163/liftoff/issues) |
| Report a reproducible bug | [Bug report](https://github.com/voyager163/liftoff/issues/new?template=bug_report.yml) |
| Suggest a feature | [Feature request](https://github.com/voyager163/liftoff/issues/new?template=feature_request.yml) |
| Report a documentation problem | [Documentation issue](https://github.com/voyager163/liftoff/issues/new?template=docs_issue.yml) |
| Report a vulnerability or sensitive security or privacy finding | The private route in [SECURITY.md](SECURITY.md) |
| Report harassment or another conduct concern | The private contact in [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md#reporting-an-issue) |

A blank issue is available when no form fits. Search existing issues first,
and add new information to an existing report rather than opening a
duplicate.

## Help us understand the problem

Include the Liftoff version or commit, your operating system, the command you
ran, what you expected, what actually happened, and a small sanitized
reproduction.

Issues and attachments are public. Remove credentials, `.env` contents,
customer data, private source, personal information and sensitive diagnostics
before posting. A tool's automatic redaction is not a guarantee that a log is
safe to share.

## Response times

Liftoff is maintained by one person. There is no guaranteed response time,
support SLA or emergency support. Clear reproductions and answers to other
people's questions are welcome contributions; see
[CONTRIBUTING.md](CONTRIBUTING.md).
