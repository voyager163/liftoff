# Getting help with Liftoff

Start with the [getting-started guide](docs/getting-started.md),
[prerequisites](docs/prerequisites.md), and
[troubleshooting](docs/troubleshooting.md).

## Choose the right channel

| You need to | Use |
| --- | --- |
| Ask a question or get help | [Public Issues](https://github.com/voyager163/liftoff/issues) |
| Report a reproducible bug | [Bug report](https://github.com/voyager163/liftoff/issues/new?template=bug_report.yml) |
| Suggest a feature | [Feature request](https://github.com/voyager163/liftoff/issues/new?template=feature_request.yml) |
| Report a vulnerability or sensitive security/privacy finding | The private route in [SECURITY.md](SECURITY.md) |
| Report harassment or another conduct concern | The separate private contact in [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md#reporting-and-enforcement) |

General issues remain available when a form does not fit. Search existing
issues first, and add relevant information to an existing report rather than
opening a duplicate.

## Help us understand the problem

Include the Liftoff version (`liftoff --version`), operating system, the command
you ran, expected and actual behavior, and a small sanitized reproduction.
Mention a managed registry if it affects installation, but do not share
credentials or internal registry configuration.

Issues and attachments are public. Remove credentials, `.env` contents,
customer data, private source, personal information, and sensitive diagnostics
before posting. A tool's automatic redaction is not a guarantee that a log is
safe to share. Do not post a sensitive finding publicly just because a private
reporting route is temporarily unavailable.

Liftoff is maintained by one person. There is no guaranteed response time,
support SLA, or emergency support service. Helpful reproductions, documentation
improvements, and answers to other users are welcome contributions.

For code changes, see [CONTRIBUTING.md](CONTRIBUTING.md). Project decisions and
maintainer responsibilities are described in [GOVERNANCE.md](GOVERNANCE.md).
