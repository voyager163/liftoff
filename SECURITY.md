# Security Policy

## Supported versions

Liftoff is being rebuilt, and no version has been released from this source
yet. Once releases exist, security fixes target the latest release only.
Upgrade and check whether the issue still occurs before reporting it.

## Report a vulnerability

**Do not disclose suspected vulnerabilities in a public issue, discussion or
pull request.**

Report privately through GitHub's vulnerability reporting form:

<https://github.com/voyager163/liftoff/security/advisories/new>

Include:

- The affected version or commit, and your operating system.
- Steps to reproduce, using synthetic data.
- The impact you observed or expect.
- Any suggested mitigation.

Do not include real credentials, customer data or other sensitive material.

## What to expect

The maintainer assesses reports privately, coordinates a fix with you, and
publishes a GitHub security advisory when disclosure is appropriate. Please
give the project a reasonable chance to release a fix before disclosing
publicly. You will be credited in the advisory unless you prefer not to be.

Liftoff has one maintainer and does not promise a response time or run a
paid bug-bounty program. If the private form is unavailable, do not post the
finding publicly; try again later.

## Other concerns

Use [SUPPORT.md](SUPPORT.md) for public technical help and the private contact
in [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md#reporting-an-issue) for conduct
concerns. Do not use security advisories to report conduct issues.
